# Security policy

The project is currently an engineering MVP for trusted single-user/project
hosts and has no formal public release or support window.

Report suspected vulnerabilities privately to the repository owner. Include:

- affected revision;
- minimal reproduction;
- impact;
- redacted task/event identifiers;
- suggested mitigation if known.

Do not include credentials, proprietary source, private artifacts, or complete
database files in a report.

See [docs/SECURITY.md](docs/SECURITY.md) for the threat model, implemented
controls, and known limitations.
